LLM Pulse is an all‑in‑one AI search visibility platform that tracks brand mentions, citations, sentiment and share of voice across AI search engines such as ChatGPT, Perplexia, Gemini and Google AI. It helps businesses monitor their reputation and discover AI‑generated content about their products.

**Areas:** AI Search Visibility · Prompt Tracking · Agent Analytics · AI Traffic · SEO · PR · E‑commerce

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for LLM Pulse: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
